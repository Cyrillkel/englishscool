# English School — сайт-визитка

Сайт-визитка преподавателя английского в стилистике [aliabdaal.com](https://aliabdaal.com).
Стек: **Next.js (App Router) + TypeScript + Tailwind CSS 4**, архитектура — **FSD (Feature-Sliced Design)**.

## Запуск

```bash
pnpm install
pnpm dev      # http://localhost:3000
pnpm build    # продакшен-сборка
```

## Структура (FSD)

```
src/
├── app/          # Слой приложения + роутинг Next.js (layout, globals.css)
├── views/        # Страницы (в FSD — «pages», переименовано из-за Next.js)
│   └── home/     # Главная: собирает виджеты
├── widgets/      # Крупные блоки страницы
│   ├── header/       # Шапка с навигацией
│   ├── hero/         # Первый экран + цифры
│   ├── services/     # Услуги
│   ├── about/        # Обо мне
│   ├── testimonials/ # Отзывы
│   ├── contact-cta/  # Контакты / запись на урок
│   └── footer/       # Подвал
├── features/     # (пока пусто) — формы записи, фильтры блога и т.п.
├── entities/     # (пока пусто) — курс, отзыв, статья блога и т.п.
└── shared/
    ├── config/site.ts   # Имя, контакты, навигация — правится в одном месте
    └── ui/              # Кнопки, секции, заглушки картинок
```

Правило импортов FSD: слой может импортировать только из слоёв ниже
(`views → widgets → features → entities → shared`).
